## Dimension A — 软件架构质量 {#dimension-a}

### A1. AWS Well-Architected Framework (6 支柱)

> 评估云原生应用架构在 6 个核心支柱的成熟度。

| 支柱         | 评分       | 评价                                                                                                                                |
| ------------ | ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **运维卓越** | ⭐⭐⭐⭐   | CI/CD (GitHub Actions + Vercel), Sentry 三层监控 (server/client/edge), 结构化日志 (`withLogging` 200 处), 但缺 runbook 和告警自动化 |
| **安全性**   | ⭐⭐⭐⭐   | guardRoute 5 级守卫 (235 处), CSP + 安全 headers (7 个), bcrypt 12 轮, CSRF 双提交, 但 6 个 API 未受 guard 保护                     |
| **可靠性**   | ⭐⭐⭐⭐   | LLM 降级回退 (Anthropic→OpenAI→Groq), 错误边界 (14 处), try-catch (442 处), 但无自动重试中间件                                      |
| **性能效率** | ⭐⭐⭐½    | Turbopack dev, AVIF/WebP 图片, 但仅 9 个 dynamic import, 无 edge runtime 利用, 无 ISR/SSG                                           |
| **成本优化** | ⭐⭐⭐⭐⭐ | 双模型策略 (Sonnet 叙事 / GPT-4o-mini 结构化), prompt caching, LLM usage tracking, Neon serverless 按用量                           |
| **可持续性** | ⭐⭐⭐⭐   | 极简依赖 (26 prod deps), 精准覆盖阈值, 无冗余框架                                                                                   |

**综合**: 4.1/5 → **8.2/10**

**亮点**: 成本优化是亮点中的亮点 — 双模型路由 + prompt caching + usage tracking 三位一体，在 solo developer 产品中极为罕见。

**改善点**: 性能效率可通过更多 edge runtime、ISR 和 dynamic import 提升。

- **任务感知路由**: 不是简单的负载均衡, 而是根据任务特性选择最佳模型
- **成本优化闭环**: 路由 + 缓存 + 追踪 三位一体
- **零信任 LLM**: CI 级别禁止绕过路由器直接调用 LLM

## 评测结论

### 32 框架综合评分: **8.4/10 (A-)**

**维度排名**: AI/LLM (9.0) > 代码质量 (8.6) > 架构 (8.5) > DevOps (8.4) > 数据工程 (8.1) > 安全性 (7.3)

**核心发现**:

1. **AI/LLM 架构是产品的护城河** — model-router 设计、prompt 工程、成本优化三维均达到 S/A+ 级别, 在同类产品中处于领先地位
2. **状态机是最优雅的架构决策** — 旅程 FSM 在 DB 和应用层双重执行, 是整个评测唯一的满分项
3. **安全性需要自动化补强** — 基础防护扎实 (guardRoute, CSP, CSRF), 但缺少自动化安全扫描和事件响应能力
4. **单人 + AI 协作达到了团队级别质量** — 136K LOC, 838 tests, 0 type error, 1.4% 技术债 — 在 solo developer 产品中几乎找不到对标

**对标参考**: 这个代码库的工程质量相当于一个 5-8 人全栈团队运营 6-12 个月的产出, 且在 AI 架构设计上超过大多数同等规模的团队。
