| `/approver` | 方案审批与决策辅助（创始人视角） | 多方案选择、提案评估 |
| `/research` | 深度研究与竞品分析               | 竞品调研、学术文献   |

### 运维 & 工作流

| Skill       | 用途                        | 触发场景       |
| ----------- | --------------------------- | -------------- |
| `/workflow` | 工作流编排器（串联 Skills） | 不知道用什么时 |
| `/triage`   | 问题分诊与任务分派          | 告警/反馈处理  |
| `/loop`     | 定时循环执行命令            | 轮询/定期检查  |
| `/preview`  | Claude Preview 实时视觉验证 | UI 改动后验证  |
| `/ship`     | 提交+分支+推送+创建 PR      | 开发完成后     |

### 业务测试 & 审计

| Skill               | 用途                                           | 触发场景                 |
| ------------------- | ---------------------------------------------- | ------------------------ |
| **`/audit`**        | **全维度统一入口（5 维度并行 + 综合仪表盘）**  | **全面审计、上线前检查** |
| **`/journey-test`** | **全链路用户旅程体验测试（浏览器操控+截屏）**  | **上线前、大版本验收**   |
| `/biz-audit`        | 业务逻辑正确性（评分管道、原型、报告、职业库） | 评分对不对、管道验证     |
| `/perf-audit`       | 性能瓶颈（LLM 超时、SSE、内存、包体积）        | 加载慢、内存泄漏         |
| `/ux-audit`         | UX 审计（Nielsen、认知走查、文案、无障碍）     | 体验检查、流程困惑       |
| `/security-audit`   | 安全漏洞（OWASP、LLM 注入、权限绕过、STRIDE）  | 安全审计、渗透测试       |
| `/edge-audit`       | 边缘场景（弱网、并发、浏览器兼容、状态恢复）   | 超时场景、edge case      |
| `/audit-fix`        | 审计优化执行器（修复审计发现的问题）           | 审计修复时               |

> `/audit` = 统一入口。`quick` ~5min | 默认 ~30min | `full` ~60min | `{biz|perf|ux|security|edge}` 单维度。
> 配套 MCP Server: `playwright` (Microsoft) + `chrome-devtools` (Google) — 提供真实浏览器控制和性能测量。
