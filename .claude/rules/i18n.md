# i18n 硬规则

- **英文站零中文，中文站零英文** — 所有用户可见文本走 i18n 字典，禁止 `isZh ? "中文" : "English"` 硬编码
- 新增文本 → 先加字典 key → 再在组件中引用
- **LLM 输出语言 = 站点 locale** — 每个 prompt 必须含语言指令 (`"Respond entirely in English"`)，locale 从请求链路一路传递到 prompt 构建
- 修改 `lib/i18n/dictionaries/en/*.json` → 必须同时改 `zh/*.json` → `npm run lint:i18n` 验证
